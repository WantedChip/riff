# riff

A curated monorepo and live showcase of front-end design riffs, high-fidelity UI clones, interactive animation labs, and interface experiments.

[![Deploy Status](https://img.shields.io/badge/edge-active-10b981.svg)](https://riff.sohamlabs.workers.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![Build](https://img.shields.io/badge/build-passing-brightgreen.svg)](#)

Riff is an editorial showcase and launcher unifying multiple independent, 100% static web builds under a single edge-hosted domain powered by Cloudflare Workers Static Assets. Each project represents an original reimagining of an interface or interactive experiment built with zero runtime fluff, instant edge delivery, and sub-100ms first contentful paint.

Live deployment: [riff.sohamlabs.workers.dev](https://riff.sohamlabs.workers.dev)
