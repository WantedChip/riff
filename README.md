# riff

A collection of front-end design riffs — practice builds and reimaginings of interfaces I find interesting. Each one is my own code and my own assets: names, images, and design all changed, nothing copied wholesale. Think of it like a musician riffing on a melody rather than covering it note-for-note — no attribution implied or given.

Live at [riff.sohamlabs.workers.dev](https://riff.sohamlabs.workers.dev)
